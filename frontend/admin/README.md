# 📚 E-Learning App – Admin Panel (React)

This is the **Admin Panel** for the [E-Learning App (Flutter)](https://github.com/tanvir-robin/E-Learning-App-Flutter), built using **React**. It allows administrators to manage courses, users, categories, and payments through a secure and intuitive dashboard.

---

## ✨ Features

- Admin login and role-based access
- Course & category management
- User & instructor control
- Payment tracking via SSLCommerz
- Firebase Firestore & Storage integration
- Dashboard analytics and reports

---

## 🛠️ Tech Stack

- **Frontend:** React, Tailwind CSS
- **Backend:** Firebase (Auth, Firestore, Storage)
- **Payment:** SSLCommerz
